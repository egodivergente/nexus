# Provider logos

Original PNG assets supplied by the user from their Google Drive logos collection.
Files are bundled locally so model identification does not depend on remote image URLs.

The collection contains 42 distinct brand/model logos. Repeated same-name Drive
entries are represented once, using the smallest original PNG. No images were
redrawn or re-encoded. Personal photos and unrelated branding are excluded.

Included: Anthropic, Atlas Cloud, Black Forest Labs, ByteDance, Claude, DeepSeek,
Doubao, ElevenLabs, ERNIE, Flux, GLM, Google, Grok, Hailuo, HappyHorse, Hunyuan,
Ideogram, Kimi, Kling, Krea, LongCat, Luma, Microsoft, Midjourney, MiniMax,
Moonshot, Nano Banana, NVIDIA, OpenAI, Pika, PixVerse, Qwen, Runway, Sora,
Stability AI, Suno, Tripo, Vidu, Wan, xAI, Z.ai and Z-Image.

The model identity comes from generation metadata when available. A logo identifies
the model or provider; unavailable media previews retain an explicit text label.
Family logos take priority over parent-company logos within a model path (for
example, `google/nano-banana` uses Nano Banana). Unknown brands keep the generic
media icon. Importing a file whose name mentions a model does not assign a brand.
