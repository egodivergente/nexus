# NEXUS

Estudio de creación con IA para Android y escritorio: catálogo de modelos, formularios dinámicos y biblioteca multimedia.

El proyecto reúne la aplicación Android en `app/`, el escritorio en `desktop/` y componentes de agentes en `agent-core/`, `agent-proxy/` y `agent-skills/`.

[Ficha pública de producto](https://github.com/vidaltb94-collab/vidaltb94-collab/blob/main/PROJECTS.md#nexus). Las ramas de auditoría de escritorio y las variantes Android conservan sus cambios por separado; esta portada no las fusiona ni afirma equivalencia con la instalación actual.
