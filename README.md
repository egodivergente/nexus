# NEXUS

Reúne modelos de imagen, vídeo y audio, sus opciones de generación y los resultados en una misma aplicación.

El flujo pasa de elegir modelo y referencias a preparar la petición, seguir el trabajo y guardar sus resultados. Los formularios cambian según las opciones de cada modelo.

## Código

- `app/`: aplicación Android.
- `desktop/`: aplicación de escritorio.
- `agent-core/`, `agent-proxy/` y `agent-skills/`: componentes del asistente.

[Escritorio](desktop/README.md) · [Proxy del asistente](agent-proxy/README.md) · [Pruebas](https://github.com/vidaltb94-collab/vidaltb94-collab/blob/main/VALIDATION.md#nexus).

Las ramas conservan revisiones distintas. Las generaciones necesitan el proveedor y las credenciales configurados; el catálogo guardado permite navegar, pero no confirma disponibilidad ni precio de cada modelo.
