# Interfaz S25 1.8.5

Integración sobre 1.8.4 (0fe1fe8), la versión instalada en el S25. Conserva biblioteca de proyectos, selección, borrado, ZIP y transporte Flow actuales.

Un único modo Agente incluso con preferencias antiguas. Navegación Agente / Lienzo / Modelos / Biblioteca por deslizamiento horizontal, con estado conservado. Historial deja de ser una pestaña. Cabeceras de 48 dp, márgenes de 8 dp y navegación inferior sin relleno vertical adicional. Se conserva el rediseño compacto y los paneles contextuales actuales. Se elimina la segunda aplicación de espacio del teclado en el chat.

VersionCode 29. No se ejecutan pruebas ni auditorías de funcionamiento por petición del usuario. Actualización mediante ADB install -r, sin borrar datos.
